# AI learning log

Complete this honestly as you work. Do not claim an experiment or review you have not performed.

For each learning cycle record:
- Topic you did not understand
- Exact question/prompt used
- Explanation rewritten in your own words
- Independent mini-experiment and command/output
- What you initially misunderstood
- The code or test changed as a result
- Commit hash (if committed)

Suggested cycles: unique unordered pairs; derived standings and tie-break sorting; JSON validation and atomic state replacement.
